1. Clique em **Novo Template**.
2. Em **Dados do Modelo**, escolha o **Procedimento Relacionado**, informe o **Título do Template** e a
   **Descrição Curta**. Marque **Gerar Tarefas Automáticas** se cada item deve virar uma tarefa ao aplicar o modelo.
3. Clique em **Salvar Dados Básicos**. Só depois disso dá para adicionar seções.
4. **Nova Seção**: título (ex.: "Documentos Pessoais") e descrição opcional.
5. Em cada seção, **+ Item**:

| Campo | Observação |
|---|---|
| **Título do Item** | ex.: "Cópia autenticada do RG/CPF" |
| **Observação Padrão** | dica ou instrução para quem vai cumprir |
| **Prazo (dias)** | contado a partir da aplicação do modelo; padrão de 7 dias |
| **Prioridade (1–10)** | padrão 5 |
| **Responsável Padrão** | opcional |

Use as setas para reordenar seções e itens.
