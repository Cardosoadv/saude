Em **Gestão › Templates de Checklist** ficam os modelos de checklist: listas padronizadas de passos e
documentos (ex.: "Inventário Extrajudicial"), aplicadas rapidamente a processos e casos.

- Filtre por **procedimento** ou gerencie os procedimentos no botão ao lado do filtro.
- Em cada modelo: **Editar**, **Duplicar** (para criar uma variação) e **Excluir**.
- O selo **Gera Tarefas** indica que, ao aplicar o modelo, o sistema cria as tarefas de cada item.

Para montar um modelo, veja [Montar um modelo de checklist](template.md).

## Aplicar a um processo

No detalhe do processo, use o cartão **Checklists** para aplicar um modelo e marcar os itens conforme avança.
