## Busca da barra superior

O campo de busca da barra superior **filtra a lista da tela em que você está**. Ele não procura no sistema
inteiro. O texto de exemplo dentro do campo indica o que ele aceita:

| Tela | O que a busca encontra |
|---|---|
| Contratos | contrato, cliente |
| Fornecedores | fornecedor |
| Leads (CRM) | nome, e-mail, telefone |
| Tarefas | título, detalhes |
| Notícias | notícia |
| Clientes e demais telas | cliente |

Para limpar a busca, clique no **×** dentro do campo. Ao trocar de tela, a busca é limpa automaticamente.

## Busca da documentação

Na tela **Documentação**, o campo no topo do índice procura em todas as páginas que você pode ver.
Ele não diferencia maiúsculas nem acentos. Use as setas para escolher um resultado e **Enter** para abrir.

> [!DICA]
> Na documentação, a tecla **/** leva direto para o campo de busca.
