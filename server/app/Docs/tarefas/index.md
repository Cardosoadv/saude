Em **Gestão › Tarefas** ficam as tarefas operacionais do escritório. Os contadores mostram o **Total** e
quantas estão **A Fazer**, **Fazendo** e **Feito**.

## Kanban ou Lista

- **Kanban**: colunas por situação. **Arraste o cartão** para mudar a situação.
- **Lista**: todas as tarefas em linhas, com prazo, situação e prioridade.

Cada tarefa mostra o prazo, o responsável e o vínculo (processo, cliente ou caso), que leva direto ao item.

## Criar uma tarefa

Clique em **Nova Tarefa**, ou crie a partir de um processo (**Ações Rápidas › Tarefa**) ou de uma intimação.

| Campo | Observação |
|---|---|
| **Título da Tarefa** | obrigatório. Ex.: "Protocolar recurso" |
| **Prazo** | obrigatório |
| **Status** | **A Fazer**, **Fazendo**, **Feito**, **Cancelado** ou **Eventos** |
| **Prioridade** | de **Muito Baixa** a **Urgente** |
| **Responsável** | busque pelo nome, e-mail ou usuário |
| **Descrição** | detalhes |
| **Enviar notificação no prazo** | avisa o responsável quando o prazo chegar |

As tarefas pendentes também aparecem no [Painel](../primeiros-passos/painel.md).
