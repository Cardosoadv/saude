Em **Financeiro › Transferências** ficam as movimentações entre contas do própria clínica (ex.: do banco
para o caixa interno). Uma transferência não é receita nem despesa: só muda o dinheiro de lugar.

## Nova transferência

1. Clique em **Nova Transferência**.
2. Preencha **Descrição / Motivo**, **Valor**, **Data**, **Conta de Origem** e **Conta de Destino**.
3. **Rateio** (opcional): **Adicionar Rateio** para cada sócio ou profissional, ou **Dividir Igualmente**. O sistema
   avisa se o total dividido não bater com o valor.
4. Clique em **Salvar Transferência**.

Na lista, use o lápis para editar e a lixeira para excluir.
