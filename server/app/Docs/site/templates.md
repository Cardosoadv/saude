**Site › Templates do Site** mostra os templates instalados, com versão, autor e origem. Por padrão, só o Super Admin acessa.

- **Enviar template (.zip)**: instala ou atualiza um template. O pacote é validado antes; se for recusado, nada é
  instalado e a tela lista os erros.
- **Ativar**: troca o visual do site. **Ativar um template nunca apaga nem altera o conteúdo do site.**
- **Páginas de exemplo**: adiciona as páginas de exemplo do template.
- **Exportar**: baixa o template em .zip.
- O template ativo e os templates do sistema não podem ser removidos.
