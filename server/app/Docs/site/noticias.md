**Site › Notícias (Site)** lista as notícias com data, categoria e status (**Publicado** ou **Rascunho**).

## Escrever uma notícia

1. Clique em **Nova Notícia**.
2. Preencha **Título da Notícia**, **Categoria** e **Status**.
3. **Data de Publicação** é opcional: em branco, vale a data do dia ao publicar.
4. **Resumo / Linha Fina**: aparece nas listas de notícias.
5. Escreva o **Conteúdo Completo** no editor (negrito, listas, links, imagens…).
6. Preencha o título e a descrição para o Google (SEO).
7. Clique em **Publicar Notícia** (ou **Salvar Alterações**, ao editar).

## Categorias

Toda notícia pertence a uma categoria. Para criar, renomear ou excluir categorias, clique em **Categorias**
no topo da lista de notícias.

- **Nome** é obrigatório e não pode repetir outra categoria.
- **Endereço (slug)** é opcional: em branco, é gerado a partir do nome (sem acentos, com hífens).
- **Descrição para o Google** (até 160 caracteres) é opcional.
- Uma categoria com notícias não pode ser excluída: mova as notícias para outra categoria antes.
