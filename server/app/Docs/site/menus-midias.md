## Menus

**Site › Menus do Site** mostra uma aba para cada menu do template (cabeçalho, rodapé, laterais).

- **Adicionar item**: um item aponta para uma página do site, para uma âncora (seção da página) ou para um
  endereço externo.
- O menu aceita **um nível de submenu**.
- Cada menu é salvo inteiro, de uma vez, em **Salvar menu**. **Descartar** desfaz o que não foi salvo.

## Mídias

**Site › Mídias do Site** é a biblioteca de imagens do site público. Envie as imagens aqui e escolha-as nas
seções das páginas.

> [!DICA]
> Descreva cada imagem no **texto alternativo**: ajuda quem usa leitor de tela e melhora o resultado no Google.
