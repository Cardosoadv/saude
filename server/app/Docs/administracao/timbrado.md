**Gestão › Timbrado (Revisão)** mostra o papel timbrado aplicado aos documentos e relatórios impressos pelo
sistema, para conferência.

Os dados do escritório nos documentos gerados (nome, endereço, contato) vêm das
[configurações do site](../site/configuracoes.md).
