A tela **Configurações** (menu **Gestão › Configurações**) reúne a administração do sistema em abas:

| Aba | Para que serve |
|---|---|
| **Sistema** | parâmetros do sistema (chave e valor). Veja [Parâmetros e manutenção](configuracoes.md). |
| **Usuários** | cadastro de usuários, grupos e permissões. Veja [Usuários e grupos](usuarios.md). |
| **Integração IA (MCP)** | conexão de assistentes de IA ao sistema. Veja [Integração com IA](integracao-ia.md). |
| **Módulos** | ligar e desligar módulos. Só aparece para quem pode gerenciar módulos. Veja [Módulos](modulos.md). |
| **Google Drive** | fila de criação das pastas de clientes e processos no Drive. Só aparece para administradores. Veja [Parâmetros e manutenção](configuracoes.md#sincronizacao-de-pastas-do-drive). |
| **Banco de Dados** | atualizações da estrutura do banco. Veja [Parâmetros e manutenção](configuracoes.md#banco-de-dados). |

Ao lado das abas ficam os cartões **Integração Google**, **Manutenção de Cache** e **Permissões & Regras**.

> [!ATENCAO]
> As ações desta tela valem para todo o escritório. Na dúvida, fale com o responsável pelo sistema antes de alterar.
