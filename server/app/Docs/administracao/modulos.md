Em **Configurações › Módulos** fica a lista dos módulos do sistema, com o **Identificador** e o **Status** de cada um.
A aba só aparece para quem tem permissão de gerenciar módulos.

## Desativar um módulo

Use a chave ao lado do módulo. Ao desativar:

- o módulo **some do menu** e dos detalhes (cartões e abas) **para todos os usuários**;
- o sistema passa a recusar o acesso às telas e dados dele;
- a documentação do módulo também deixa de aparecer.

**Nenhum dado é apagado.** Ao reativar, tudo volta como estava.

> [!ATENCAO]
> O módulo **Administrativo** é essencial e não pode ser desativado: sem ele, ninguém conseguiria reativar os outros.

Se alguém estiver com uma tela do módulo aberta no momento em que ele é desativado, o sistema avisa que o
módulo foi desativado e volta para o Painel.
